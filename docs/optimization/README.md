# QLIE Switch 运行时优化手册

覆盖 WHJ2、WHJ4 和 WHJ6 移植中的 GPU 渲染、影片和动态 CG、资源和音频、界面和存档。每章列出机制、对应版本及测量范围。

1. [GPU 渲染、呈现和着色器](gpu.md)
2. [影片解码、动态 CG 和音画时序](video.md)
3. [资源预读、音频、界面与存档](runtime.md)
4. [基准和复核方法](verification.md)
5. [《美少女万華鏡異聞 雪女》专用优化](whj6.md)

目标画布为 1280×720，呈现上限为 60 Hz，保留原图层顺序、混合与演出时钟。Switch 默认使用 deko3d，可切换 Vulkan/NVK，也保留 CPU 参照路径。正式构建关闭运行日志和性能探针。

WHJ2 开发版 NRO `bc2e4ec` 已通过实机使用验收。项目维护者也已完成 WHJ4 的 Switch 实机使用测试。正式构建沿用 deko3d 和 60 Hz 上限。

提交简写标识引入或修正该优化的版本，部分指向发布前的开发提交。各章节将公开源码、开发版本、Mac 测量和 Switch 设备观察分别标明。构建与依赖见[项目说明](../../README.md)，第三方依赖见[许可与来源](../../THIRD_PARTY.md)。
