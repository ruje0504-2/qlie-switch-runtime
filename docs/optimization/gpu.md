# 1. GPU 渲染、呈现和着色器

[返回目录](README.md)

## 两个后端共用的优化

- Vulkan 和 deko3d 共用场景命令和纹理缓存，把画面划分为 16×16 图块。绘制命令和纹理未变时复用原图块，新增图元可以复用已有合成结果。不透明图元完整覆盖图块时，可省去被遮住的绘制。
- 两套计算着色器共用图块合成和像素公式，包括纹理采样、混合、遮罩与渐变。Vulkan 的片元路径也复用像素公式。Switch 分别嵌入 Vulkan 的 SPIR-V 与 deko3d 的 DKSH。
- 两个后端都能在画面不变时跳过呈现，并跟踪各显示图像中需要更新的图块。Vulkan 在表面支持时按区域复制。deko3d 可把本帧新算出的图块直接写入取得的显示图像，再补齐该图像中其他过期图块。

图块缓存和图元裁剪最初随 `4cc2044`、`5942b7e` 和 `f753506` 等 Vulkan 优化演进，deko3d 接入后复用了现有场景逻辑。

## Vulkan/NVK 的后端实现

| 版本 | 优化 |
|---|---|
| `fef8705`、`a115c92` | 原生 NWindow 负责呈现，SDL 负责事件和音频。按表面能力选择区域复制或全屏着色。 |
| `21c5b67` | 片元与计算着色器统一查表布局，复用可保留的场景内容。 |
| `ee2459b`、`023d29a` | 在固定 Mesa 26.2.4 的 GM20B NAK 中缩短成对、无条件的片元互锁范围。将允许重排的采样放在等待之前，保留原票据和内存顺序。NVK 使用独立的着色器缓存指纹。 |

驱动提供有序片元互锁时可用实例绘制，其他路径按图块计算。几何、纹理、字形、规则遮罩和渐变继续按原顺序合成。七组定点像素对照覆盖遮挡、渐变和交换链回补。目标 NRO 已核实链接到对应 NAK 函数和缓存指纹。该互锁改动的同场景实机前后对照待补。 [Mesa Switch](https://github.com/danfromtico/mesa-switch)

## deko3d 的后端实现

Switch 实机使用反馈估计，deko3d 的渲染效率比 Vulkan/NVK 高约 50%。现有记录未注明这个估算的指标，也未保存同场景的两后端配对数据。

| 版本 | 优化 | 证据 |
|---|---|---|
| `ced2f97`、`c49d703` | 增加原生 deko3d 图块合成和 DKSH 离线编译，设为默认后端。 | Mac 离屏适配覆盖九种混合和五类效果。目标 DKSH 已核。 |
| `194779a` | 更改图块直接写入当前显示图像和保留画布，按各张图像的损伤回补。精简双线性、减色和规则遮罩。 | 花海四组、剧情五组逐字节一致。一次全帧直写省去 3,686,400 字节的画布读取。目标寄存器 78→70。 |
| `f26204e` | 简单运动与复杂叠层使用各自内核。平移背景、投影竖边在 GPU 图块内复用坐标。 | Mac M4 / MoltenVK 同帧各 16 对，标题 GPU 着色中位数 3.184→2.927 ms，剧情 1.754→1.575 ms。像素一致。 |
| `a8f2926` | 同位、同尺寸的完整位图改图时精确比较图块。独占不透明底图走专用内核，三张显示图像各自跟踪过期区域，碎片回补合并成一次计算派发。完整位图的精确比较当前只在 deko3d 启用。 | Mac M4 真实标题和剧情各 18 对，配对中位着色时间下降 7.24% 和 22.86%。保留画布及显示图像逐字节一致。 |

`194779a` 的设备日志中，22 个全屏样本均直写 3,600 图块、呈现复制为零，各有一次全屏计算。同期没有 PMU 采样。`6822bc7` 的高图元数全屏场景另有 11 个样本，着色中位数 16.480 ms、PMU 中位数 98.2%。两批分别对应各自的场景和版本。`b94d8d1` 起，正式构建关闭 PMU 读取和 GPU 时间戳采样。

## 运行时共用的转场快照优化

开发版本 `8dd4dbc` 在最终全画布被不透明纯色覆盖时直接产生正确快照。`456ebac` 为原点对齐的单张透明位图应用原定点混合，复杂场景仍由 GPU 捕获。在同一 Mac 实景夹具中，后者取样为 ARM 0.286 ms、MoltenVK 1.378 ms，24 对完整快照一致。原场景叠化和绘制顺序保留。
